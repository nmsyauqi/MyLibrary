Jagawarung

JagaWarung is a simple app for phones and computers. It helps small shops run sales, track items, and watch money live. It uses cloud storage to keep all data safe and synced.

Project Overview

JagaWarung is a high-performance, multiplatform Point of Sale (POS) system built with Flutter and Cloud Firestore to streamline retail operations for MSMEs. Driven by a reactive Provider architecture, the app connects cashiers and store owners through real-time data synchronization. The cashier portal enforces strict operational discipline with mandatory opening-cash validation, blocks duplicate active shifts, and accelerates checkout via a hybrid mobile/tablet UI with integrated camera barcode scanning (mobile_scanner). It also features a live stream listener that instantly terminates a cashier's session and redirects them to the shift initialization screen the moment an owner triggers a remote force-close.

For store owners, the application serves as a remote command center featuring an administrative dashboard that updates sales charts and revenue metrics instantly upon transaction completion. Owners can manage staff credentials, modify access PINs, audit cash discrepancies against system logs using professional correction tools, and control the entire product catalog with full CRUD capabilities. By replacing traditional API polling with live Firestore Stream Listeners, JagaWarung ensures strict financial concurrency control and seamless data integrity across all devices, wrapped in a modern, adaptive design utilizing Plus Jakarta Sans and Inter typography.

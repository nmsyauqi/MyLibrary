Project Overview

This project is a full-stack web application built entirely on Laravel Livewire, delivering a seamless, real-time Single-Page Application (SPA) experience without the overhead of complex JavaScript. At its core, the platform features a dynamic gamification system where users earn points through daily checklists, driving engagement via personal progress charts and a global leaderboard.

The application architecture utilizes a dual-role ecosystem: Participants track their daily tasks and view compliance calendars, while Admins utilize a dedicated dashboard for complete task management (CRUD), user administration, and cross-user compliance monitoring. User onboarding is streamlined through an intelligent "Magic Entry" login flow that automatically detects and handles registration or sign-in in a single step. Wrapping the entire experience together is a distinctive, custom-crafted User Interface built from scratch using TailwindCSS, meticulously designed to emulate a nostalgic Retro OS (Windows 98) theme complete with classic windows, a functional taskbar, and tactile 3D buttons.
